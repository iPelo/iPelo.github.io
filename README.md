# iPelo.github.io

🌐 **Live:** [ipelo.github.io](https://ipelo.github.io)

Personal portfolio for [@iPelo](https://github.com/iPelo). Single-file static site — drop into a GitHub Pages repo and it's live.

## Stack
- Vanilla HTML / CSS / JS (zero build step, zero dependencies)
- `<canvas>` for the live neural-network background
- IntersectionObserver for scroll reveals
- Custom cursor + typography from Google Fonts (Fraunces + JetBrains Mono)

## Structure
```
index.html   ← everything (HTML, CSS, JS) in one file
README.md    ← this file
```

## Easter egg
Type `maths` anywhere on the page. 🤯
